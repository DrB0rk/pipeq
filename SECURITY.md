# Security policy

## Supported versions

Only the latest published version receives security fixes while PipeQ is pre-1.0.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub’s private vulnerability reporting for the repository, or contact the maintainer privately through the account’s verified contact method.

Include:

- affected version and environment;
- reproduction steps or a minimal proof of concept;
- impact, especially if commands, credentials, or audio routing can be affected;
- any suggested mitigation.

Please allow reasonable time for investigation before public disclosure.
